
# Question and Answer Platform

## About the Project

The Discuss is a web application developed using PHP and MySQL. It allows registered users to ask questions and answer questions posted by other users. Users can browse questions by category and view the latest questions through the navigation menu.

## Features

- **User Registration:** New users can create an account.
- **User Login:** Registered users can log in to the platform.
- **Ask Questions:** Logged-in users can post questions.
- **Answer Questions:** Logged-in users can answer questions posted by others.
- **Latest Questions:** View the most recently posted questions.
- **MySQL Database:** Store and manage user accounts, questions, and answers.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Bootstrap


## Requirements

- PHP
- MySQL
- Apache web server
- XAMPP or another compatible local development environment
- Web browser

## Installation and Setup

1. Clone or download this repository.
2. Place the project folder inside the `htdocs` directory of XAMPP.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create a database for the project.
5. Import the project's SQL file if one is included in the repository.
6. Configure the database connection details in the appropriate PHP configuration file.
7. Open the following URL in your browser:

   `http://localhost/your-project-folder/`

   Replace `your-project-folder` with your actual project folder name.

## How to Use

1. Open the application in your browser.
2. Register a new account.
3. Log in using your credentials.
4. Browse questions through the Categories menu.
5. View recent posts through the Latest Questions menu.
6. Ask questions and answer questions posted by other users while logged in.

## Database

MySQL is used to manage the application's data, including user accounts, questions, answers, and any additional information supported by the application.
